## 更新内容

- 新增 Sparkle 自动更新：允许自动检查后，定期检测新版本，并引导下载、安装与重新启动。
- 应用菜单和菜单栏新增“检查更新…”，支持简体中文和 English。
- 更新安装包使用 Ed25519 签名验证；发布流程自动生成并上传更新清单。

旧版本尚未包含更新器，请手动安装一次本版本。后续版本即可通过应用内更新。

## What's new

- Added Sparkle automatic updates. Once automatic checking is allowed, quick periodically checks for new versions and guides downloading, installation, and relaunch.
- Added **Check for Updates…** to the application and menu bar menus, in Simplified Chinese and English.
- Update downloads are verified using Ed25519 signatures. Releases now include an automatically generated update feed.

Older versions do not include the updater. Install this version manually once to receive future updates within quick.

## 安装 / Installation

下载 `quick-0.0.6-macos-arm64.dmg`，打开后将 `quick.app` 拖入“应用程序”。需要 Apple Silicon Mac 和 macOS 27 或更新版本。

Download `quick-0.0.6-macos-arm64.dmg`, open it, and drag `quick.app` to Applications. Requires Apple Silicon and macOS 27 or later.

当前构建采用临时签名，未经 Apple 公证。Current builds use ad-hoc signing and are not notarized by Apple.
