## 安装 / Installation

下载 `quick-0.0.5-macos-arm64.dmg`，打开后将 `quick.app` 拖入“应用程序”。需要 Apple Silicon Mac 和 macOS 27 或更新版本。

Download `quick-0.0.5-macos-arm64.dmg`, open it, and drag `quick.app` into Applications. Requires an Apple Silicon Mac running macOS 27 or later.

当前构建采用临时签名，未经 Apple 公证。Current builds use ad-hoc signing and are not notarized by Apple.

校验下载 / Verify the download:

```bash
shasum -a 256 -c quick-0.0.5-macos-arm64.dmg.sha256
```
